# Element Bound medallions

Painted element and result badges created by the Owner (mynamejeff625-png)
for Element Bound. See `docs/DESIGN.md` §5a for where and how they are used.

- 256×256 WebP, transparent background, trimmed to a clean circle.
- Show at **32 px or larger** only; smaller sizes use the SVG glyphs in `assets/icons.svg`.
- Processing: trimmed from the Owner's 1600 px originals (heart and storm from
  ~990 px JPGs with the white background removed), anti-aliased circular mask,
  resized with Lanczos, WebP quality 88.

| File | Meaning |
|---|---|
| `fire` `water` `nature` `earth` `lightning` `air` | Prime elements |
| `magma` (Fire + Earth) `storm` (Lightning + Air) `bloom` (Water + Nature) | Hybrid elements |
| `heart` | Vitality |
| `trophy` | Victory, Trial mastered |
| `draw` | Duel draw |

To replace one, keep the file name and the same processing so every screen
updates without code changes.
